## Автоматизированная система управления приёмной кампанией и личными кабинетами ИжГУ

### О проекте

Веб-приложение для автоматизации приёма документов на поступление, обработки заявлений, формирования приказов о зачислении и обеспечения личными кабинетами всех участников образовательного процесса.

**Функциональные возможности:**

- Регистрация и авторизация с хэшированием паролей
- Ролевая модель (7 ролей: абитуриент, студент, преподаватель, сотрудник, ректор, администратор)
- Подача документов онлайн с загрузкой сканов (паспорт, СНИЛС, документ об образовании)
- Управление статусами заявлений (индивидуально и массово)
- Предложение о зачислении и механизм согласия/отказа
- Издание приказов с загрузкой PDF
- Административная панель (факультеты, специальности, пользователи, FAQ)
- Публичный портал с поиском и фильтрацией специальностей
- Загрузка аватаров через AJAX
- API для динамической загрузки данных

### Установка и запуск

#### 1. Клонирование репозитория

```bash
git clone https://github.com/ваш-репозиторий/izgu-admission.git
cd izgu-admission
```

#### 2. Создание виртуального окружения

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Linux/macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

#### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

#### 4. Настройка базы данных

При первом запуске база данных и начальные данные создаются автоматически. Начальные данные включают:

- 8 факультетов
- 5 специальностей
- 7 пользователей (администратор, ректор, преподаватели, сотрудник, студент, абитуриент)
- Вступительные испытания
- 7 стандартных вопросов FAQ

#### 5. Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: `http://127.0.0.1:5000`

### Решение типовых проблем

**Ошибка «модуль не найден»**
```bash
pip install -r requirements.txt
```

**База данных не создаётся**
```bash
python
>>> from app import app, db
>>> with app.app_context():
...     db.create_all()
```

**Порт 5000 занят (Windows)**
```bash
netstat -ano | findstr :5000
taskkill /PID <PID> /F
```

**Порт 5000 занят (Linux/macOS)**
```bash
lsof -i :5000
kill -9 <PID>
```
